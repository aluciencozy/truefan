# Researched graph replacements

These are new, original paraphrases of episode-specific sources, reviewed by the coding agent. They replace the existing AI caches; they are not imports of extraction-probe candidates. Canon accuracy and exact reveal timing have not been independently verified by watching the episodes. API provenance remains `verified: false` and graphs remain experimental.

## Scope

Six units each: Fate/Zero, Fate/stay night (2006), Unlimited Blade Works (2014, including the prologue as unit 1), Fate/Apocrypha, The Apothecary Diaries, and Dragon Ball (1986). One Piece covers episode 1 because its cached episode total is unknown and currently bounded to one. This is early-story coverage, not a complete series catalog.

The empty failed cache for AniList 139074 (Destiny, a music entry) is removed only if it still has no published or working episodes. All other caches, user progress, library preferences, community content and quota history are preserved.

## Review choices

Fate adaptations are kept separate. Servant identities are omitted when unnecessary. The escaped homunculus remains unnamed until Apocrypha unit 5; his new name keeps the same node ID and earlier relationships. Episode recaps are the evidence boundary: no character-page biographies or later-episode information were used to fill gaps. Relationships describe explicit directed actions rather than guessed permanent alliances. Source evidence fields are paraphrases, not quotations.

## Applying and maintaining

From `backend/`, run `python -m scripts.replace_generated_graphs` for a live dry run. To apply: `python -m scripts.replace_generated_graphs --apply --backup /absolute/private/path/graphs-before.json`. Use a persistent private directory for the backup; the file must not already exist and must be outside this repository. It contains original rows (including requester IDs), is written with mode 0600 and synced before database writes. Retain it for rollback.

The command locks only the named cache rows and uses the shared job lock. It validates all replacements before mutation, replaces the published and working documents in one transaction, and clears leases to fence existing workers. Missing targets, an occupied cleanup target, or media progress bounds mismatches abort the entire swap. It never runs schema initialization or clears generation history.

Researched caches are marked `source_curated` and reject automatic start/retry/extend/refresh overwrites. Edit the reviewed data and re-run this backed-up command to update them. Their model provenance is `source-curated/v1`, meaning researched data rather than an inference model. `HF_MODEL` remains unchanged for other titles.

Keep `GENERATION_EPISODE_CAP=6`, `GENERATION_JOBS_PER_USER=3`, `GENERATION_GLOBAL_DAILY_LIMIT=20`, `GENERATION_MAX_CONCURRENT=2`, and `GENERATION_LEASE_SECONDS=180`. Reading these caches uses neither inference credits nor generation quota. Those limits still bound new AI jobs, and changing them does not change Hugging Face billing. No backend environment variables are removed or edited.

## Validation

Run the regular backend unittest suite. `TRUEFAN_TEST_DATABASE_URL` enables disposable-schema Postgres tests for atomic scope, private backups, failed validation, preservation of progress/history, lease fencing and overwrite protection. Never use a public-schema seed or database wipe for this operation.
